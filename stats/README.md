# 全网统计（「胜全国 N%」的数据来源）

这个目录放**所有人上报的成绩汇总**，板子联网时会读 `latest.json` 来算真实的「胜全国 N%」。

## 怎么上报

1. 打开板子的**统计页**（UP/DN 翻到「统计」，或串口发 `PAGE 10`）
2. 到 GitHub 提一个 [成绩上报](../../issues/new?template=stats.yml) issue，填 4 个数字：
   - 成功次数、失败次数（统计页「本周 成 / 败」）
   - 连续成功天数
   - 有记录的天数（「最近记录」有几行）
3. 机器人会自动汇总、回复一句，并更新本目录两个文件

## 文件

| 文件 | 内容 |
|---|---|
| `reports.json` | 每条上报的原始数字 + 算出的分数（同一 issue 重编辑会覆盖） |
| `latest.json` | 板子读的汇总：`{"users":人数, "buckets":[99 个数], "updated":"时间"}`，`buckets[i]` = 分数恰好 `i+1` 的人数 |

## 分数公式（固件和汇总脚本必须一致）

```
分数 = int(成功率 × 0.6) + int(min(连续天数, 30) × 1.2) + min(记录天数, 7)
钳到 1..99
```

对应 `main.c` 的 `stats_percentile()` 和 `tools/aggregate_stats.py` 的 `score_of()`。
改了公式两边都要改，否则「胜全国」会算歪。

## 板子读不到怎么办

校园网/公司网经常把 `raw.githubusercontent.com` 的 DNS 过滤掉（作者学校就是这样），
这时板子会**退回本地估算**，统计页上的标记会从「网」变成「估(本地)」。

想手动刷一次（联网正常时）：

```
NETSTAT
```

返回 `{"ok":true,"users":N}` 说明拉到了，`{"ok":false,"err":"net"}` 说明没连上。

## 隐私

只收 4 个数字，不收账号、SSID、IP、MAC 或任何能定位到人的信息。
