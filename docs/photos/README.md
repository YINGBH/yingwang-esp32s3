## 脱敏处理

这些照片是手机直出的，原始文件带两处不该公开的信息，都在发布前处理过：

1. **裁掉底部水印** —— 原图底部那条相机水印带里有**拍摄地点、日期时间、机型署名**，
   直接裁掉整条底栏（不保留任何可读文字）。
2. **屏幕内容打码** —— 状态页上真实出现的 WiFi 名（家里路由）、内网 IP、以及信息页的
   城市名，都做了马赛克；其余内容（已认证、信号、电源、运行时长、模型参数、价签信息）保留原样。

发布出去的 JPEG **不含 EXIF**（GPS / 拍摄时间 / 机型 / 作者都已被重新编码丢掉），
可以用 `exiftool` 或任何看图工具确认。

处理参数见仓库外的脚本：裁到水印带起点（y=1844 / 1910×2194），马赛克块 16px，
输出 1200 宽、JPEG q82、渐进式。

## 没有放进去的

还有几张手机直出图**故意没用**：

- 屏幕背景用了动漫壁纸的两张（时钟页 / 桌面摆拍）——壁纸有版权，不适合随仓库分发；
- 同一场景的重复角度。

## 补拍建议

要是有新照片，按这个来：长边 1200～1600 px、单张 < 400 KB；屏幕正对拍、关环境灯减少摩尔纹；
**拍到真实 SSID / 内网 IP / 城市 / 账号一律打码**。
