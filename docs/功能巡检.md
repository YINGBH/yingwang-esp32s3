## WiFi 观察项（未定性）

日志里能看到周期性掉线重连：

```
I (10314) wifi:state: assoc -> run (0x10)
I (16314) wifi:state: run -> init (0xf00)
W (16394) wifi: 断开（reason=15），第 2 次重连
I (28794) wifi:state: assoc -> run (0x10)
```

- `reason=15` = **四次握手超时**（4WAY_HANDSHAKE_TIMEOUT）
- 开机阶段因此可能卡在「正在连接 WiFi 中」60 秒左右
- **不是扫描功能引起**：掉线发生在 BLE 尚未启动时（16 秒），而推价签要"上线 30 秒后"才触发

嫌疑排序：AP 侧握手问题 / 信号弱 / 省电策略。下一步可以做：开 `CONFIG_ESP_WIFI_PS_NONE`、记录 RSSI 与掉线时间点对比。
