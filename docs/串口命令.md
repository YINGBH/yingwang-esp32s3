# 串口命令 / 网页后台

波特率 115200，一行一条命令，回包是 JSON。网页后台（USB 连上后浏览器打开板子 IP）
用的是同一套接口，改配置的效果和串口一样，写完直接进 NVS。

## 常用

| 命令 | 作用 |
|---|---|
| `GET` | 读配置和运行状态 |
| `AUTH` | 立刻认证一次（不看探测结果，用来测链路） |
| `SET key=value` | 改配置（见下表） |
| `PAGE n` | 切页：0 状态 / 1 信息 / 2 时钟 / 3 日历 / 4 诊断 / 5 系统 / 6 价签 |
| `SHOT` | 导出当前屏幕帧（PNG） |
| `LOG n` / `LOGF n` | 读 RAM 日志 / flash 日志（n = 条数） |
| `REBOOT` | 重启 |

## 背景图

`BGR`（开始）→ `BGD`（数据，分块）→ `BGE`（结束）→ `BGC`（清除），
网页后台传背景图走的也是这套。

## 改配置

```
SET key=value
```

| key | 含义 |
|---|---|
| `ssid` / `pass`（`wifi_pass`） | WiFi 名称 / 密码 |
| `user` / `pwd`（`portal_pass`） | 宽带账号 / 密码 |
| `static_ip` | 静态 IP，空 = DHCP |
| `rot` | 屏幕方向 0/90/180/270 |
| `brightness` | 背光 0–100 |
| `screen_off` | 无操作多少分钟息屏，0 = 常亮 |
| `charge_off` | 插着电时是否也按上面的分钟数息屏：`1` 允许 / `0` 插电常亮（默认） |
| `off_bright` | 息屏后的背光：`0` 全黑并清屏（防残影）/ `1..100` 低亮度常显（能瞄一眼时间） |
| `city` / `lat` / `lon` | 天气用的城市和经纬度 |
| `portal_base` | 门户地址，如 `http://10.0.0.1:8090`；填 `-` 回到编译期默认 |
| `portal_ac` | AC 的 IP（跳转 URL 里的 `wlanacip`） |
| `portal_ssid` | 校园网 SSID，**大小写敏感** |
| `birthday` | 生日 mmdd，0 = 不设置 |
| `portal` | `1` / `0` 开启或关闭门户认证 |
| `tick` / `mac` / `rotgap` | 时钟跳动 / 价签 MAC / 屏幕旋转偏移（调试用） |

### 外观（主题 / 装饰）

| 命令 | 说明 |
|---|---|
| `SET theme=0..10` | 配色：0 深蓝 · 1 纯黑 · 2 森林 · 3 紫罗兰 · 4 暖白 · 5 初音 · 6 洛天依 · 7 鹿乃 · 8 爱莉希雅 · 9 蕾姆 · 10 赤红 |
| `SET theme_bg=0xRRGGBB` | 自定义背景色（16 进制，网页的取色器直接给这个格式） |
| `SET theme_accent=0xRRGGBB` | 自定义强调色；给了这两个就自动变成"自定义主题" |
| `SET deco_border=0..3` | 边框：0 无 · 1 细线 · 2 圆角 · 3 双线 |
| `SET deco_icon=0..5` | 角标图标：0 无 · 1 星星 · 2 爱心 · 3 音符 · 4 樱花 · 5 月亮 |
| `SET deco_tag=初音` | 左下角角标文字（≤4 字，`-` 表示清空） |

装饰颜色跟随主题的强调色；有背景图时会自动把文字强制成亮色，保证看得清。

### 电池续航

| 命令 | 说明 |
|---|---|
| `SET batt_est=2` | 满电预计能用几小时（默认 2，见下表的 200mAh） |
| `SET batt_used=0` | 把"已用时间"清零（换了电池 / 刚充满时手动校准） |
| `SET batt_low=15` | 剩余多少分钟算低电量（默认 15，0 = 用默认） |
| `SET batt_keep=1` | 低电量时保持常亮，不自动息屏（默认 1） |
| `SET probe_sec=120` | **电池供电时**的联网探测间隔（秒，默认 120，最小 10） |
| `SET probe_plugged=1` | 插电时也用 `probe_sec`（默认 0 = 插电仍 15 秒） |

探测间隔直接影响功耗：15 秒一次约 100mA，120 秒一次降到约 60-70mA，
200mAh 电池从 **1 时 48 分** 拉到 **2 时 45 分** 左右。代价是断网/认证失效发现得慢一点。
| `GET` | 回 `batt_used`（已用分钟）、`batt_est` |

顶栏右侧在**电池供电**时显示「剩 1时20分」，插着电（充电中）不显示。

板子没有电池电压 ADC，只能按时间推算：电池供电时累加真实时间，充电时按约 2 小时充满的速度回补。
所以它是**估算**，不是库仑计。200mAh 电池的参考值：

| 用法 | 平均电流 | 满电可用 |
|---|---|---|
| 屏幕全亮常开 | ~150 mA | **1 时 12 分** |
| 混合（大部分时间 AOD） | ~100 mA | **1 时 48 分** |
| 全 AOD | ~75 mA | **2 时 24 分** |
| 极省电（少联网） | ~50 mA | **3 时 36 分** |

公式：`小时 = 200mAh × 0.9 ÷ 平均电流(mA)`

### 界面 / 页面

| 命令 | 说明 |
|---|---|
| `PAGE <n>` | 切到第 n 页（见下表） |
| `SHOT` | 把当前屏抓成 RGB565 原始数据（网页后台会自动显示） |

| n | 页面 | n | 页面 |
|---|---|---|---|
| 0 | 状态 | 6 | 价签 |
| 1 | 信息 | 7 | 倒计时 |
| 2 | 时钟 | 8 | 秒表 |
| 3 | 日历 | 9 | 作息（4 个闹钟汇总） |
| 4 | 诊断 | 10 | **统计** |
| 5 | 系统 | 11 | 模型（只能长按 BOOT 进，不在翻页循环里） |

「统计」页内容：今天 成功/失败/掉线次数、本周合计、连续成功天数、
最近 7 天逐日记录，以及**本地估算**的「胜全国 N%」。

> ⚠️ 「胜全国 N%」是**本地估算**：设备没有服务器，拿不到真实全国数据。
> 公式见 `发布说明.md`，纯属趣味指标，别当真实排名。
