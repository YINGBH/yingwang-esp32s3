# 串口命令 / 网页后台

波特率 115200，一行一条命令，回包是 JSON。网页后台（USB 连上后浏览器打开板子 IP）
用的是同一套接口，改配置的效果和串口一样，写完直接进 NVS。

## 常用

| 命令 | 作用 |
|---|---|
| `GET` | 读配置和运行状态 |
| `AUTH` | 立刻认证一次（不看探测结果，用来测链路） |
| `SET key=value` | 改配置（见下表） |
| `PAGE n` | 切页：0 状态 / 1 信息 / 2 时钟 / 3 日历 / 4 诊断 / 5 系统 / 6 价签 |
| `SHOT` | 导出当前屏幕帧（PNG） |
| `LOG n` / `LOGF n` | 读 RAM 日志 / flash 日志（n = 条数） |
| `REBOOT` | 重启 |

## 认证相关

| 命令 | 作用 |
|---|---|
| `CAPTCHA` | 取一张验证码并本地识别（不提交） |
| `CAPIMG` | 导出最近一张验证码 PNG |
| `PORTALHTML` | 导出最后一次登录响应的原文，排查失败原因 |
| `LOGOUT` | 注销当前在线会话 |
| `RECONNECT` | 重连 WiFi |
| `WIFIOFF` / `WIFION` / `WIFIHARD` | 关 WiFi / 开 WiFi / 硬复位 WiFi |

## 电子价签

| 命令 | 作用 |
|---|---|
| `ESL` | 推一次信息页（天气 / 日历） |
| `ESLPREP` | 只渲染不推送（调试排版） |
| `ESLTEST` | 推测试图 |
| `ESLIMG` | 推自定义图 |
| `RESETPUSH` | 清除“今天已推过”的标记 |

## 背景图

`BGR`（开始）→ `BGD`（数据，分块）→ `BGE`（结束）→ `BGC`（清除），
网页后台传背景图走的也是这套。

## 调试

| 命令 | 作用 |
|---|---|
| `TASKS` | 任务栈 / CPU 占用 |
| `FLOGC` | 清 flash 日志 |
| `DNS` / `DNSNEXT` | 看当前 DNS / 换一个 |
| `PING` | 探一下网络通不通 |
| `WX` / `WXREFRESH` | 看 / 刷新天气 |
| `MICRAW` / `NOISE` | 麦克风原始数据 / 环境噪声百分比 |
| `SPLASH` | 开机动画 |
| `VOL n` | 音量 |

## 改配置

```
SET key=value
```

| key | 含义 |
|---|---|
| `ssid` / `pass`（`wifi_pass`） | WiFi 名称 / 密码 |
| `user` / `pwd`（`portal_pass`） | 宽带账号 / 密码 |
| `static_ip` | 静态 IP，空 = DHCP |
| `rot` | 屏幕方向 0/90/180/270 |
| `brightness` | 背光 0–100 |
| `screen_off` | 无操作多少分钟息屏，0 = 常亮 |
| `charge_off` | 插着电时是否也按上面的分钟数息屏：`1` 允许 / `0` 插电常亮（默认） |
| `off_bright` | 息屏后的背光：`0` 全黑并清屏（防残影）/ `1..100` 低亮度常显（能瞄一眼时间） |
| `city` / `lat` / `lon` | 天气用的城市和经纬度 |
| `portal_base` | 门户地址，如 `http://10.0.0.1:8090`；填 `-` 回到编译期默认 |
| `portal_ac` | AC 的 IP（跳转 URL 里的 `wlanacip`） |
| `portal_ssid` | 校园网 SSID，**大小写敏感** |
| `birthday` | 生日 mmdd，0 = 不设置 |
| `portal` | `1` / `0` 开启或关闭门户认证 |
| `tick` / `mac` / `rotgap` | 时钟跳动 / 价签 MAC / 屏幕旋转偏移（调试用） |

### 外观（主题 / 装饰）

| 命令 | 说明 |
|---|---|
| `SET theme=0..10` | 配色：0 深蓝 · 1 纯黑 · 2 森林 · 3 紫罗兰 · 4 暖白 · 5 初音 · 6 洛天依 · 7 鹿乃 · 8 爱莉希雅 · 9 蕾姆 · 10 赤红 |
| `SET theme_bg=0xRRGGBB` | 自定义背景色（16 进制，网页的取色器直接给这个格式） |
| `SET theme_accent=0xRRGGBB` | 自定义强调色；给了这两个就自动变成"自定义主题" |
| `SET deco_border=0..3` | 边框：0 无 · 1 细线 · 2 圆角 · 3 双线 |
| `SET deco_icon=0..5` | 角标图标：0 无 · 1 星星 · 2 爱心 · 3 音符 · 4 樱花 · 5 月亮 |
| `SET deco_tag=初音` | 左下角角标文字（≤4 字，`-` 表示清空） |

装饰颜色跟随主题的强调色；有背景图时会自动把文字强制成亮色，保证看得清。

### 自动化

| 命令 | 说明 |
|---|---|
| `SET deco_grid=0/1` | 淡网格背景 |
| `SET theme_auto=0/1` | 按日出日落自动换主题 |

| `SET bg_rotate=0/1/2` | 背景图轮换：0 不换 · 1 每小时 · 2 每天（需要两张图） |

### 墨水屏界面

| 命令 | 说明 |
|---|---|
| `SET esl_layout=0/1` | 0 标准（日历 + 天气面板）· 1 大字日期（大号日期 + 星期 + 天气一行 + 日出日落） |
| `SET esl_opts=N` | 位开关：1 日历 · 2 天气 · 4 日出日落 · 8 品牌版本（相加，如 15=全开、6=只要天气和日出日落） |
| `SET esl_text=今天也要加油` | 自定义一行字（最多 16 字，只在大字布局显示，`-` 清空） |

> 字库现在有 **4281 个汉字**：手写表 + 源码自动扫描 + 《通用规范汉字表》一级 3500 字
> + 一言（Hitokoto）语料里的 3780 字。签名/励志短句基本不会缺字；
> 仍缺的字显示成 `?`，要扩就改 `tools/gen_esl_font.py` 的字表再重新生成。

### 签名 / 一言

| 命令 | 说明 |
|---|---|
| `HITO` | 联网拉一句一言，写进价签的自定义文字（拉不到就用固件内置的 80 句） |

三级来源：官方接口 `http://v1.hitokoto.cn/`（走 80；这个网络里 HTTPS 443 会被重置）
→ 仓库里的 `docs/quotes.txt` → 固件内置句库。
后两级是给「DNS 被校园网过滤」这种情况兜底的，实测这台机器就是最后一级生效。

### 自定义图片（价签）

| 命令 | 说明 |
|---|---|
| `SET esl_img=0/1/2/3` | 0 关 · 1 整屏图片 · 2 左半图片+右侧天气 · 3 左侧日历+右半图片 |
| `EIMG B` | 开始上传（会擦除旧的） |
| `EIMG D <偏移> <hex>` | 写一片（**每片 ≤16 字节**：命令行超过约 80 字符会被截断） |
| `EIMG Q` | 查已收字节数和 CRC32 |
| `EIMG E` | 结束并保存 |
| `EIMG X` | 删除自定义图片 |

上传用现成工具，别手打：

```bash
# 1) 转图（需要 Pillow）
python tools/upload_esl_image.py --convert 图片.png --out esl.bin
# 2) 上传（需要 pyserial），顺便设成整屏图片模式
python tools/upload_esl_image.py COM3 --planes esl.bin --mode 1
```

图片会被自动缩放到 296×128（保持比例、居中裁切），红/黑/白三色量化。
