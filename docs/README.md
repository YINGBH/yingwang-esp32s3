# docs / 图片目录

## 真机截图

`screen_preview.png` 是六屏拼图，`screens/` 下是单张原图。这些**都是板子自己的屏幕截图**：
固件把 240×240 帧缓冲导出（网页后台的 `SHOT` 指令 / USB 工具），再 2× 放大成 480×480。

| 文件 | 页面 |
|---|---|
| `screens/status.png` | 状态（已认证、WiFi、IP、信号、电源） |
| `screens/info.png` | 信息（时间、日期、天气、日出日落、空气质量、在线时长） |
| `screens/calendar.png` | 日历（月视图、农历、距元旦天数） |
| `screens/esl.png` | 电子价签（待机、屏型号、按键说明） |
| `screens/sys.png` | 系统（固件版本、编译时间、内存、模型、账号） |
| `screens/model.png` | 模型（版本、参数、张量、输入输出、支持的学校） |
| `screens/boot.png` | 对时中（NTP 同步） |

### 网页后台

`web-page.png` 是 USB 网页工具（`web/index.html`）的界面截图，用无头浏览器渲染的，
表单里全是占位值（`HomeWiFi` / `13800000000` / `10.0.0.1`），不含真实配置。

### 还差一屏：诊断（板载日志滚动）

诊断页现在**不放波形图了**，是「板载日志」：从 flash 日志环里取最近 10 条 `ESP_LOG`，
面板 10 行、最多显示 5 条；级别用左边小色块区分（E 红 / W 黄 / I 绿），越旧越暗；
某一条太长（超过 2 行）时，是**这一条自己**每 700ms 滚动一块，不是整屏往上翻。
第一批截图（10-31，`文档/截图/page_4_diag.png` 那份）还是旧版「延迟/丢包/波形/声音电平」，
**和现在的固件不一致，所以没有放进拼图**。

要补这一屏，在设备上：

1. 短按 BOOT 翻到「诊断」页（或网页后台发 `PAGE 4`）；
2. 等几秒让日志刷出来；
3. 网页后台点「导出屏幕帧」，或发 `SHOT` 指令，存成 PNG；
4. 丢进 `docs/screens/diag.png`，我再并进拼图（或者你自己替换 `screen_preview.png`）。

### 个人信息打码

状态页和系统页原本显示了真实的 WiFi 名、内网 IP、门户 IP 和宽带账号。处理方式不是
简单涂黑，而是：

1. 用背景色擦掉原文字的像素；
2. 用**同一份点阵字库**（`components/bsp_nologo/font_data.h`）在原来的基线上重绘占位值。

所以打码后的样子和原界面风格一致，但显示的是：

| 原来 | 现在 |
|---|---|
| WiFi 名 | `HomeWiFi` |
| 内网 IP | `192.168.1.100` |
| 门户 / AC IP | `10.0.0.1` |
| 宽带账号 | `13800000000` |

图片里**不含**任何真实账号、手机号、SSID、内外网 IP 或 MAC。
